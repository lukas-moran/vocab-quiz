# 词序 · 英语词汇测验

本地运行的英语词汇库与中译英测验网页。支持多词性、多条中文释义，以及从词库随机抽取 20 个单词生成测验。

## 启动

在此目录运行：

```powershell
python server.py
```

然后打开：

```text
http://127.0.0.1:4173
```

也可以从项目根目录运行：

```powershell
python .\vocab-quiz\server.py --port 4173
```

## 功能

- 添加英文单词，并为同一单词记录多个词性和全部中文释义
- 输入单词后自动查询词性与中文释义，也可点击“自动补全”手动触发
- 编辑、删除及撤销删除单词
- 按单词、中文释义或词性搜索筛选
- 从词库随机抽取 20 个不同单词生成中译英四选一测验
- 即时判分、键盘 A-D 作答、结果统计与错题复盘
- 数据保存在当前浏览器的 `localStorage` 中

首次打开时会自动加入 26 个示例单词，因此可以直接体验完整测验。删除或修改示例内容后，刷新页面不会自动恢复。

自动补全优先使用内置示例词库；其他单词通过本地 `server.py` 请求有道词典，需要网络连接。查询结果会填入表单，但不会自动保存，保存前可以继续修改。
